# PM 開發需求確認計畫模板

當工程師收到 PM 或業務單位的開發需求並完成評估規劃後，產出此文件供 PM 再次確認需求範圍、系統影響、業務流程、例外規則與待決策事項。

## 文件開頭

```md
# 需求開發確認計畫：{功能或模組名稱}
```

## 建議章節

### 1. 需求背景與目標

客觀說明需求由來、欲解決之業務問題與本次預期達成之成果。

- **需求背景**：說明業務痛點、法規要求或功能擴充背景。
- **本次目標**：具體說明本功能完成後之系統行為與產出。
- **範疇邊界 (Scope)**：

| 項目 | 說明 |
|---|---|
| 納入範圍 (In-Scope) | 本次實作明確涵蓋的功能與處理項目 |
| 排除範圍 (Out-of-Scope) | 本次明確不處理、留待後續階段或非本系統負責之項目 |

### 2. 影響範圍評估 (Impact Analysis)

評估本次修改對既有系統、模組、資料庫或圖台之關聯影響：

| 系統 / 模組 | 影響範圍 | 影響程度 | 說明 |
|---|---|---|---|
| {系統或模組名稱} | {影響之畫面/API/資料表} | 高 / 中 / 低 | {影響說明與相容性考量} |

### 3. 資料來源與欄位介接規劃

說明資料來源與關鍵欄位之映射關係（使用業務欄位與系統欄位對照，不展開底層程式碼）：

- **資料來源說明**：說明資料提供方（如第三方 API、資料庫/SDE、使用者匯入檔案等）。
- **關鍵資料對應表**：

| 來源欄位 / 參數 | 系統對應欄位 | 說明 / 格式與比對規則 |
|---|---|---|
| `{來源欄位名}` | `{系統欄位名}` | {型態、必填、比對依據或轉換邏輯} |

### 4. 業務運作流程與處理規則

#### 4.1 正常運作流程

依序描述系統執行之業務邏輯步驟：

1. **觸發機制**：說明啟動方式（如排程時間、手動按鈕、事件觸發）。
2. **資料處理與比對邏輯**：說明資料篩選條件、關聯比對規則與資料運算方式。
3. **結果呈現與寫入**：說明資料儲存目標、圖台更新或介面顯示方式。

#### 4.2 例外與異常處理規則 (Edge Cases)

列出邊界情況與系統預計之處理方式，供 PM 確認業務合理性：

| 情境 | 預計處理機制 | PM 確認 / 建議備註 |
|---|---|---|
| 外部服務連線失敗 / 逾時 | 重試機制或記錄錯誤 Log 並發送通知 | |
| 資料缺漏或查無對應代碼 | 略過該筆資料或填入預設值 | |
| 來源資料重複 | 覆寫既有資料或保留最新一筆 | |

### 5. 產出結果與介面變更

- **畫面 / 操作變更**：若涉及 UI，說明操作入口、按鈕位置、操作提示訊息與確認視窗文案。
- **產出檔案 / 報表**：說明匯出檔案格式、命名規則、存放路徑與保留期限。
- **通知機制**：若有通知或告警，說明發送條件、收件對象與信件重點內容。

### 6. 實作階段規劃 (Phases & Deliverables)

依交付項目劃分階段（不填寫預估工作天數，僅列產出與項目）：

| 階段 | 預計工作項目 | 預估產出 / 交付物 |
|---|---|---|
| Phase 1 | {核心資料介接與排程/批次邏輯} | {核心資料流可正常跑通並寫入 DB} |
| Phase 2 | {圖台/介面功能整合與呈現} | {測試環境可操作完整介面與檢視圖層} |
| Phase 3 | {例外通知、手動補跑功能與整體交付} | {功能完整交付進行驗收} |

### 7. 外部相依與前置需求 (Dependencies)

條列需 PM 或外部單位協調開通或提供之資源：

- [ ] **權限 / 帳號**：需申請之 API Key、主機或資料庫連線權限。
- [ ] **環境 / 資源**：需確認之網路通訊、伺服器規格或儲存空間。
- [ ] **測試資料**：需 PM 或客戶提供之範例檔案或測試案例資料。

### 8. 待 PM 拍板決策事項 (Decisions Needed)

列出需求評估過程中發現需進一步決策之商業規則，並提供工程建議：

1. **{決策事項一}**：說明問題背景與選項。（*工程建議：提供具體建議方案與理由*）
2. **{決策事項二}**：說明問題背景與選項。（*工程建議：提供具體建議方案與理由*）

## 寫作原則

- 文字風格保持客觀中立，聚焦於事實、邏輯、範圍與限制。
- 專注於業務與系統層級邏輯，避免直接列出底層程式碼（如 Class、Interface、底層函式庫調用）。
- 明確區分「已確認需求」與「待決策事項」，待確認項目需附上工程建議選項供 PM 評估。
